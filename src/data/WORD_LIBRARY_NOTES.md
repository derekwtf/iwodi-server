# 词库整理记录

最近整理：2026-10-07。游戏从一个词组的 `words` 中随机抽取两词，因此三词组必须保证任意两词都能形成可玩的配对。两词的平民／卧底方向随机，不以正常／离谱、正面／负面决定身份。

## 选词原则

- 不只找相似词，要找**能暂时承接同一句描述、又会被具体细节拆穿的两种指代**。连接点可以是外形、动作、共同叙述框架或关系隐喻，不要求同一物种或用途。
- 人工复核新词对的共同描述及分歧：不能只靠「都有」「能用」「有人喜欢」这样的空泛共同点；要能继续问到对象、场合、频率、后果或情绪。
- 优先选择多数玩家认识的词。可以用婚丧、身体糗事、职场讽刺和神怪设定，但不靠冷门人物履历、时效梗或强行谐音支撑整局。
- 纯同义词、同类名词排排坐、上位词包含下位词而缺少有效差异的词组可以删除，不为保持数量而保留。
- 本次新增全部用**双词组**，让设计好的反差实际被抽到；不为了多算两个配对而塞入第三词。保留的旧三词组仍按全部两两组合校验。
- 原有八类保留 ID，并拓宽到现实／虚构的跨界搭配；新增类别按主要笑点归档。不增加新玩法或额外加权，继续按词组均匀随机，分类出现概率随组数变化。

### 删减与精修

| 类别 | 删除 | 主要原因及例子 |
| --- | ---: | --- |
| 成语表达 | 60 组 | 纯近义词消耗描述空间，例如「全神贯注／聚精会神／专心致志」「势均力敌／旗鼓相当／不相上下」。保留有对象、意图或情绪差异的表达。 |
| 人物 | 19 组 | 冷门人物知识门槛或缺少独特的共同描述，例如「顾恺之／吴道子／郑板桥」「张韶涵／王心凌」。不是全面移除历史、艺术或明星题材。 |
| 美食 | 8 组 | 过密的菜谱变体、上位词包含或低识别度，例如「蛋炒饭／扬州炒饭／酱油炒饭」「醋溜白菜／酸辣白菜」。 |
| 城市出行 | 7 组 | 地名堆叠或同义称谓，例如「首尔／东京／大阪」「弄堂／胡同／巷子」。 |
| 日常用品 | 7 组 | 范围高度重叠，例如「书桌／写字台／电脑桌」「湿厕纸／湿纸巾」。 |
| 传统与自然 | 6 组 | 过多依赖地理、树种知识或关系松散，例如「黄山／庐山／峨眉山」「瀑布／峡谷」。 |
