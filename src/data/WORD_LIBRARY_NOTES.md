# 词库整理记录

整理日期：2026-09-27。游戏从一个词组的 `words` 中随机抽取两词，因此三词组必须保证任意两词都能形成可玩的配对。

## 选词原则

- 两词要有共同的描述空间，同时存在玩家能逐步推理出的差异；避免完全无关、纯同义或仅靠一字之差的组合。
- 优先选择多数玩家认识、能从外观、用途、场景或人物关系描述的词。典故和历史人物保留适量进阶内容。
- 公开词单只作候选，逐组核对后再收录；排除过时梗、表述错误、范围过宽和重复配对。
- 分类按主要玩法场景划分：旅行交通与场所归「城市出行」，山川动植物归「传统与自然」，家电归「日常用品」，线上行为和数码设备归「数码互联网」。
